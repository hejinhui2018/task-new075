# 联合改稿工作台

公关团队的联合改稿工具：品牌与法务从同一版新闻稿各自修改后，把**共同底稿、品牌版、法务版**三方按段落自动合并，冲突逐个人工解决；合并后再做**承诺事实与交叉引用校核**，防止「文字合上了、数字失真了」。所有数据保存在浏览器本地（localStorage），无需后端。

技术栈：React 18 + TypeScript + Vite，测试用 Vitest。

## 运行方式

```bash
npm install        # 安装依赖
npm run dev        # 开发模式（默认 http://localhost:5173）
npm test           # 运行测试（vitest run）
npm run build      # 类型检查 + 生产构建（输出 dist/）
npm run preview    # 预览生产构建结果
```

## 功能一览

### 三方文本合并

- **四栏工作台**：共同底稿 / 品牌版 / 法务版 / 合并结果并排展示，每栏独立滚动。
- **三方段落合并**（`src/lib/merge.ts`）：
  - 只有一方修改 / 删除 / 新增 → 自动采用；
  - 双方改同一段且不同 → 待处理冲突（`edit-edit`）；
  - 一方删除、另一方修改 → 待处理冲突（`delete-edit` / `edit-delete`）；
  - 双方整段重写同一段（相似度过低、按删除+新增出现时）→ 合并层重新配对为冲突，不会静默保留两份；
  - 双方新增相同内容 → 自动去重；新增不同内容 → 都保留。
- **段落移动识别**（`src/lib/diff.ts`）：基于 LCS 锚点 + 全局相似度配对，同一未匹配空隙内的配对判为「原地修改」，跨空隙判为「移动」。一方移动、另一方修改内容时，合并结果**同时保留新位置与新内容**（`move-edit`），不会误判成删除加新增。
- **冲突解决**：逐个跳转（上一处 / 下一处），每处冲突可采用品牌版、法务版、底稿原文或手动填写；已解决的可「重新处理」。

### 承诺事实与交叉引用校核

文本冲突解决的是「段落怎么写」，事实校核解决的是「数字与引用是否仍然成立」。典型场景：正文把「30 天」改成「45 天」而脚注还是旧口径；删掉一项费用后「合计 120 万」没有更新；段落移动后「见第 4 条」指向了另一件事。

- **事实抽取**（`src/lib/facts.ts`）：从底稿、品牌版、法务版与合并结果中识别**金额、比例、日期、时长、数量**五类承诺事实（支持中文数字如「十二家分行」「五千万元」），统一换算为规范单位（元 / 天 / % / 日期序数 / 个），并从数字左侧上下文提取语义标签（如「退款期限」「费用合计」）。
- **事实身份**：身份 = 所在条目 + 类别 + 语义标签，**与数值无关**。相同数字出现在不同承诺中不会按文本值误配——「退款期限 30 天」与「公测周期 30 天」是两个事实；「退款期限 30 天 → 45 天」是同一事实的新旧值。
- **合并后验证**（`src/lib/verify.ts`）：
  - **口径一致**：同一事实在正文 / 脚注等不同段落出现不同数值 → `口径不一致`（比较前先做单位换算，「1.5 个月」=「45 天」）；
  - **合计公式**：「合计 / 总计」必须等于各费用项之和，费用项被删除而合计未更新时依赖链会标出被删项 → `合计不符`；
  - **日期先后**：「自 A 至 B」起点不得晚于终点（缺年份的终点继承起点年份），同主题「开始 / 结束」日期不得倒置 → `日期顺序矛盾`；
  - **比例范围**：占比 / 覆盖率等不得超出 0–100%，同段各项「占比」之和不得超过 100% → `比例越界`；
  - **引用目标**（`src/lib/refs.ts`）：条款按文档顺序编号，引用按**底稿身份绑定**（条目 id），支持重命名条款、删除目标、段落重排与新增引用；目标移动 → `引用目标漂移`，目标删除 → `引用目标已删除`，新增引用无法解析 → `引用无法解析`。**未解析引用不会悄悄绑定到同名目标**；
  - **脚注**：正文（注 N）标记与「注 N：」定义必须互相呼应 → `脚注缺失 / 脚注未被引用`。
- **冲突面板区分两类冲突**：顶栏与图例区分「文本合并冲突」与「事实完整性冲突」；事实面板点击问题后**四栏联动**定位来源段落，并展示**来源（底稿 / 品牌 / 法务各版本值）、当前值、依赖链与受影响表述**。
- **同步更新候选**：解决上游事实时系统给出候选（如「脚注『30 天』→『45 天』」「合计『120 万元』→『90 万元』」「『第 4 条』→『第 3 条』」）。候选只改写与合并文本一致的品牌 / 法务版本，**永不改写共同底稿（比较基线）**，也**不自动改写法务锁定段落**（含声明 / 免责 / 法规引用等，显示 🔒 需手动修改）。候选采用后自动重新合并并**重新验证全部关系**。
- **确认忽略**：确认为有意为之的问题移入「已确认」，确认记录带内容指纹——事实内容再变时确认自动失效，不会掩盖新问题。

### 通用

- **撤销 / 重做**：Ctrl/Cmd+Z、Ctrl/Cmd+Shift+Z（或 Ctrl+Y），覆盖解决冲突、编辑文档、采用候选、确认忽略、恢复示例等操作。
- **两份内置示例**：「恢复示例」覆盖文本合并全部场景；「事实校核示例」包含预算合计、发布日期与公测期、脚注口径、条款引用与法务锁定段落，合并后报告 5 项事实问题。
- **可溯源**：每条结果标注来源（底稿 §n / 品牌 §n / 法务 §n）、修改方与移动关系；点击合并条目会联动定位三个来源栏中的对应段落，反之亦然。
- **可读差异**：长段落按字/词级 diff 展示（`<del>` 删除线、`<ins>` 下划线 + 文字徽标），不只靠颜色区分。
- 三个来源栏均可「编辑」粘贴自己的稿件（空行分段），保存后自动重新合并与校核；「复制合并稿」导出最终文本。

## 合并规则细节

文档按空行切分段落（无空行时退化为按行）。对每一方计算相对底稿的段落 diff：

1. 规范化后做 LCS，得到完全未动的锚点段落；
2. 未匹配的底稿段落（删除候选）与未匹配的新版段落（插入候选）按相似度（token 级 Dice 系数，阈值 0.5）全局贪心配对；
3. 同一空隙内的配对 → 原地修改；跨空隙 → 移动（可同时带修改）；
4. 剩余未配对 → 纯删除 / 纯插入。

合并时逐段组合双方操作（keep / modify / delete / move），再叠加双方的新增段落；冲突以 `底稿段号` 为稳定 id，人工解决记录按键保存，文档变更后自动清理失效记录。

## 事实校核细节

- **抽取顺序**：日期 → 季度 → 时长 → 金额 → 比例 → 数量，先抽取的类别占用字符区间，避免「2026 年」被当成时长、「3 个月」被当成数量。「5000 万」这类无「元」金额需金额语境（费 / 预算 / 合计等）才抽取。
- **身份匹配**：跨版本配对与同稿归并只看类别 + 单位兼容 + 标签相似度（token Dice 系数），绝不看数值。
- **派生值**：标签含「合计 / 总计 / 共计 / 总额 / 小计」的金额视为派生值；组成项取同段落其他金额，同段落没有时向上扫描连续的费用段落。
- **条款编号**：条款段（「第 N 条」开头）按文档顺序编号，标题里的编号只是名字——段落重排后编号随位置变化，引用校验据此发现漂移。
- **候选应用**：只替换品牌 / 法务版中与合并文本一致的段落（底稿不动），因此不会把落选版本改出新的文本冲突，也不会破坏底稿的引用绑定。
- **本地持久化（v2）**：文档（含比较基线——共同底稿）、冲突决议、事实确认记录与撤销/重做历史（各限 30 步）都保存在 localStorage；事实身份由文档与决议确定性推导，随之一并恢复。v1 存档自动迁移。

## 目录结构

```
src/
  lib/
    text.ts       段落切分与规范化
    tokenize.ts   分词、相似度、词级 diff
    diff.ts       段落级 diff（含移动识别）
    merge.ts      三方合并、冲突分类、人工解决应用
    facts.ts      承诺事实抽取、身份匹配、单位换算、法务锁定判定
    refs.ts       条款 / 引用 / 脚注抽取与底稿引用绑定
    verify.ts     事实完整性校核、同步更新候选、候选应用
    history.ts    撤销/重做（纯函数历史栈）
    sample.ts     内置示例（文本合并示例 + 事实校核示例）
    storage.ts    localStorage 持久化（v2，含撤销/重做历史）
    viewmodel.ts  界面视图模型（徽标、来源文字、问题标签）
    __tests__/    上述模块的测试
  components/     工作台 UI 组件（含 FactPanel 事实校核面板）
  App.tsx         主应用（状态、快捷键、四栏联动）
```

## 测试

`npm test` 运行 113 个用例，覆盖：

- **三方合并**：单方修改自动采用、双方一致修改、插入去重、自动删除等；
- **移动识别**：移到文末/开头、移动同时修改、相邻互换、新闻稿式结尾互换；
- **冲突分类**：edit-edit、delete-edit、edit-delete、move-move、整段重写调和；
- **人工解决**：四种解决方式、删除类冲突的解决、失效记录清理；
- **事实抽取**：五类事实、中文数字、单位换算、语义标签、干扰项（条款号/脚注号/电话）；
- **身份匹配**：相同数字在不同承诺中不误配、单位换算后相等、数量名词不兼容；
- **单位/公式**：合计校验（含删除费用项、跨段落费用、单位混合）、日期先后、比例范围；
- **引用迁移**：段落重排、重命名条款、删除目标（不悄悄绑定同名新条款）、新增引用；
- **锁定候选**：法务锁定段落只提示不改写、候选采用后重新验证通过；
- **撤销重做**：多步撤销/重做、提交清空重做栈、历史上限；
- **本地恢复**：v2 存档完整往返、v1 自动迁移、损坏存档容错；
- **端到端**：两份内置示例的完整合并与校核结果、界面渲染冒烟。
