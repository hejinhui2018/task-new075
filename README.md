# 联合改稿工作台

公关团队的联合改稿工具：品牌与法务从同一版新闻稿各自修改后，把**共同底稿、品牌版、法务版**三方按段落自动合并，冲突逐个人工解决；合并后再对**承诺事实与交叉引用**做完整性校核——正文改了「30 天」脚注不能还是旧口径，删掉一项费用「合计」必须跟着变，条款改名后「见第 4 条」不能指错地方。所有数据保存在浏览器本地（localStorage），无需后端。

技术栈：React 18 + TypeScript + Vite，测试用 Vitest。

## 运行方式

```bash
npm install        # 安装依赖
npm run dev        # 开发模式（默认 http://localhost:5173）
npm test           # 运行测试（vitest run）
npm run build      # 类型检查 + 生产构建（输出 dist/）
npm run preview    # 预览生产构建结果
```

## 功能一览

- **四栏工作台**：共同底稿 / 品牌版 / 法务版 / 合并结果并排展示，每栏独立滚动。
- **三方段落合并**（`src/lib/merge.ts`）：
  - 只有一方修改 / 删除 / 新增 → 自动采用；
  - 双方改同一段且不同 → 待处理冲突（`edit-edit`）；
  - 一方删除、另一方修改 → 待处理冲突（`delete-edit` / `edit-delete`）；
  - 双方整段重写同一段（相似度过低、按删除+新增出现时）→ 合并层重新配对为冲突，不会静默保留两份；
  - 双方新增相同内容 → 自动去重；新增不同内容 → 都保留。
- **段落移动识别**（`src/lib/diff.ts`）：基于 LCS 锚点 + 全局相似度配对，同一未匹配空隙内的配对判为「原地修改」，跨空隙判为「移动」。一方移动、另一方修改内容时，合并结果**同时保留新位置与新内容**（`move-edit`），不会误判成删除加新增。
- **冲突解决**：逐个跳转（上一处 / 下一处），每处冲突可采用品牌版、法务版、底稿原文或手动填写；已解决的可「重新处理」。
- **承诺事实校核**（`src/lib/facts.ts` / `checks.ts` / `refs.ts` / `propagate.ts`，详见下节）。
- **撤销 / 重做**：Ctrl/Cmd+Z、Ctrl/Cmd+Shift+Z（或 Ctrl+Y），覆盖解决冲突、编辑文档、采用候选、设置基线等操作；历史随状态持久化，刷新后仍可撤销。
- **一键恢复示例**：内置联合发布稿，覆盖互不冲突修改、同段冲突、删除与编辑冲突、插入、段落移动，以及预算合计、发布日期、脚注口径、条款引用等事实场景。
- **可溯源**：每条结果标注来源（底稿 §n / 品牌 §n / 法务 §n）、修改方与移动关系；点击合并条目或事实冲突会联动定位四个栏目的对应段落。
- **可读差异**：长段落按字/词级 diff 展示（`<del>` 删除线、`<ins>` 下划线 + 文字徽标），不只靠颜色区分。
- 三个来源栏均可「编辑」粘贴自己的稿件（空行分段），保存后自动重新合并与重新校核；「复制合并稿」导出最终文本。

## 承诺事实与交叉引用校核

文本合并只能发现「段落不一样」，发现不了「数字对不上」。工作台在合并结果之上再做一层事实完整性校核：

### 事实抽取与稳定身份（`src/lib/facts.ts`）

- 从四个版本（底稿 / 品牌版 / 法务版 / 合并稿）中识别**金额、比例、日期、时长、数量**，支持中文数字（「十二家」「五千万元」）与阿拉伯数字；
- 数值归一化：金额归一到元、时长归一到天、比例归一到 0~1——「120万元」与「1200000元」是同一值，「30天」与「三十天」是同一值；
- **身份 = 语义槽位**（承诺主题 + 类型），而不是数字文本：「交付 30 天」与「退款 30 天」是两条不同事实，不会按文本值误配；品牌版把「迁移窗口 30 天」改成「45 天」后槽位不变，系统知道是**同一承诺的值变了**；
- 同段多个同类事实按主题词消歧（「平台开发费用」「安全审计费用」「年度运维费用」），删掉中间一项后其余身份不错位；
- 跨版本对齐：同一底稿段落（经 diff 对应）+ 同一槽位 → 同一事实身份，与取值无关。

### 合并后验证（`src/lib/checks.ts`）

- **合计公式**：「合计 / 总计」类金额应等于分项之和，分项个数还会与「三项费用」这类声明比对；
- **日期先后**：交付 / 迁移类日期不应晚于宣布 / 发布类日期（季度按区间比较）；
- **比例范围**：覆盖率 / 占比类比例应在 0~100%（增长类表述除外）；
- **口径一致**：派生值（脚注口径、免责声明中的测算口径）应与正文定义值一致，否则判为过期；
- **引用目标**：见下。

### 交叉引用解析与迁移（`src/lib/refs.ts`）

- 识别「第N条」条款定义与「见第N条」引用、「脚注N：」定义与「详见脚注N」引用；
- 引用目标按**内容指纹**跟踪：**重命名条款**后，仍写旧名称的引用判为「待迁移」并给出迁移候选，**不会悄悄绑定到同名的新条款**；**删除目标** → 悬空；**同名目标不唯一** → 歧义（绝不静默二选一）；**段落重排**不影响解析；**新增引用**按名称解析到现有目标。

### 事实冲突面板与同步候选（`src/components/FactPanel.tsx` / `src/lib/propagate.ts`）

- 冲突面板区分两类：**文本合并冲突**（原有卡片）与**事实完整性冲突**（面板顶部紫色卡片，含类型徽标、依赖链「定义值 → 派生值 / 引用」、受影响表述）；
- 点击「定位来源」联动四栏：合并条目 + 底稿 / 品牌版 / 法务版对应段落同时滚动定位；
- 用户解决上游事实（如交付冲突采用「45 天」）后，系统自动提出**同步更新候选**（脚注 30 天 → 45 天、合计 120 万 → 85 万且「三项」→「两项」、引用「第1条」→「第2条」），逐项「采用」后修改对应来源文档，全部关系自动重新验证；
- 候选只投向与合并稿文本一致的来源段落，不会误改另一方自洽的表述；
- **法务锁定段落**（含「前瞻性声明」「免责声明」「风险提示」的段落）只提示、不提供一键采用，`applyCandidate` 会拒绝改写——系统绝不自动改写法务锁定内容；
- 事实冲突可「标记已确认」（事实决议），与文本决议一起持久化。

### 比较基线

「设为比较基线」把当前合并稿的事实值快照保存；之后任何事实值变化都会在面板中提示「较基线已变更」，可随时更新或清除基线。

### 本地持久化（`src/lib/storage.ts`，v2）

文档、文本决议、**事实决议**、**比较基线**与**撤销 / 重做历史**（各保留最近 20 步）都保存在 localStorage；旧版 v1 数据自动迁移，损坏数据静默放弃。

## 合并规则细节

文档按空行切分段落（无空行时退化为按行）。对每一方计算相对底稿的段落 diff：

1. 规范化后做 LCS，得到完全未动的锚点段落；
2. 未匹配的底稿段落（删除候选）与未匹配的新版段落（插入候选）按相似度（token 级 Dice 系数，阈值 0.5）全局贪心配对；
3. 同一空隙内的配对 → 原地修改；跨空隙 → 移动（可同时带修改）；
4. 剩余未配对 → 纯删除 / 纯插入。

合并时逐段组合双方操作（keep / modify / delete / move），再叠加双方的新增段落；冲突以 `底稿段号` 为稳定 id，人工解决记录按键保存，文档变更后自动清理失效记录。

## 目录结构

```
src/
  lib/
    text.ts       段落切分与规范化
    tokenize.ts   分词、相似度、词级 diff
    diff.ts       段落级 diff（含移动识别）
    merge.ts      三方合并、冲突分类、人工解决应用
    cnnum.ts      中文数字解析
    facts.ts      承诺事实抽取、语义槽位身份、跨版本匹配
    refs.ts       条款/脚注引用解析与迁移（内容指纹跟踪）
    checks.ts     合并后验证（合计/日期/比例/口径/引用）与比较基线
    propagate.ts  同步更新候选、法务锁定、候选应用
    history.ts    撤销/重做（纯函数历史栈）
    sample.ts     内置示例（合并场景 + 事实校核场景）
    storage.ts    localStorage 持久化（v2，含历史与基线，兼容 v1）
    viewmodel.ts  界面视图模型（徽标、来源文字）
    __tests__/    上述模块的测试
  components/     工作台 UI 组件（含 FactPanel 事实校核面板）
  App.tsx         主应用（状态、快捷键、四栏联动）
```

## 测试

`npm test` 运行 127 个用例，覆盖：

- **三方合并**：单方修改自动采用、双方一致修改、插入去重、自动删除等；
- **移动识别**：移到文末/开头、移动同时修改、相邻互换、新闻稿式结尾互换；
- **冲突分类**：edit-edit、delete-edit、edit-delete、move-move、整段重写调和；
- **人工解决**：四种解决方式、删除类冲突的解决、失效记录清理；
- **撤销重做**：多步撤销/重做、提交清空重做栈、历史上限；
- **事实抽取**：中文数字、金额/比例/日期/时长/数量归一、单位换算等价、年份不误判为时长；
- **身份匹配**：同值不同承诺不误配、同段主题词消歧、删分项不错位、跨版本值跟踪；
- **引用迁移**：重命名检测、删除目标悬空、段落重排、新增引用、同名目标不静默绑定；
- **合并后验证**：合计公式（含「N项」声明）、日期先后、比例范围、脚注口径、端到端示例；
- **同步候选与锁定**：候选生成与去向、采用后重新验证、法务锁定段落拒绝自动改写；
- **持久化恢复**：v2 往返、v1 迁移、损坏数据静默恢复、历史随状态恢复；
- **端到端**：内置示例的完整合并结果与解决后的最终稿。
